# Beancount Studio specification

[`src/index.md`](src/index.md) begins the canonical product specification and
[`src/SUMMARY.md`](src/SUMMARY.md) defines its publication order. Requirements
cover the active product-wide behavior; [`src/verification.md`](src/verification.md)
records their status and implementation evidence.

Other repository documentation is explanatory. When prose conflicts with a
`BC-*` requirement, the requirement under `spec/src` is authoritative.
