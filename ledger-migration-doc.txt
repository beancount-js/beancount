BEANCOUNT-JS LEDGER / FAVA MIGRATION SUMMARY
==============================================
Document date: 2026-06-11
Scope: Svelte 5 shell migration, obsidian/Fava parity fixes, e2e coverage,
       Svelte 4 alignment audit, and unified checks tooling.


1. OVERVIEW
-----------

This work migrated the Fava UI shell from Svelte 4 patterns to Svelte 5,
ported missing views and functionality from the original Fava/Obsidian codebase,
fixed several runtime crashes and UX regressions, added Playwright e2e tests,
and introduced guardrail scripts (prettier, eslint, svelte-check, custom Svelte 5
pattern checks) that run against source directories only—not dist/.

4. SVELTE 4 → 5 ALIGNMENT
---------------------------

4.1 Breaking pattern reference
------------------------------

| Svelte 4 (broken in Svelte 5)              | Svelte 5 fix                                      |
|--------------------------------------------|---------------------------------------------------|
| on:click on shadcn Button                  | onclick (Button uses $props; does not forward on:click) |
| slot="trigger" let:builder                 | {#snippet trigger({ props, value, ... })}         |
| builders={[builder]} on Popover.Trigger    | {...props} from trigger snippet                   |
| row.accounts() as method call              | row.accounts as getter                            |
| directive.accounts()                       | directive.accounts as getter                        |

4.2 Components migrated to Svelte 5 patterns
--------------------------------------------

Dashboard.svelte
  - Sidebar collapse: onclick on Button (not on:click)
  - Deferred persistSidebarCollapsed via queueMicrotask
  - ComboBox: migrated from slot="trigger" + builders={[builder]} to {#snippet trigger}
  - Main content pane: min-w-0 overflow-hidden

Main.svelte
  - Wrapped app in Tooltip.Provider
  - @fontsource/source-code-pro/400.css and /600.css

Nav.svelte
  - Tooltips use {#snippet child({ props })} (not asChild let:builder)

ComboBox.svelte
  - Snippet API: value, open, hasSelection, placeholder
  - $effect syncs selected state

Editor.svelte
  - Save button uses onclick (keyboard Cmd/Ctrl+S still via CodeMirror keymap)

Query.svelte, QueryBox.svelte, EditorDialog.svelte, ImportEditor.svelte,
ImportTable.svelte, Search.svelte
  - All shadcn Button on:click → onclick
