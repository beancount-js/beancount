# UI-owned shadcn-svelte components

This section renders the editable shadcn-svelte source owned by `@lapis/ui`. It is the visual and behavioural reference for the shared theme tokens and component contracts that applications consume.

Fava's original local source remains unchanged while application imports are migrated. New shared work belongs here, not in a Fava-local wrapper.

## How to use this catalog

- Check the component story before adding or changing a UI pattern. Stories cover the supported variants, semantic structure, and interactive states.
- Use the catalog theme switcher to review the same shared tokens as the applications. Do not introduce Storybook-only visual overrides.
- Keep each story beside its source component. Update its story whenever the component’s public behaviour or visual states change.
- Import a shared primitive from `@lapis/ui/shadcn/<family>` when it exists. Do not duplicate it in application source.

## Component groups

- **Actions:** Button, Button Group, Toggle, and Toggle Group
- **Forms:** Input, Textarea, Switch, Select, Calendar, and Command
- **Disclosure:** Accordion, Collapsible, and Tabs
- **Overlays:** Alert, Alert Dialog, Dialog, Dropdown Menu, Menubar, Popover, Sheet, and Tooltip
- **Layout:** Breadcrumb, Pagination, Resizable, Scroll Area, Separator, Sidebar, and Skeleton
- **Data display:** Badge, Data Table, Empty, Progress, and Table

Fava also contains copied Drawer and Range Calendar source, but neither is currently imported by the app. They intentionally stay out of this catalog until that changes.

For APIs and upstream examples, see the official <a href="https://shadcn-svelte.com/docs/components">shadcn-svelte component documentation</a>.
