# Query

`Query` combines the BQL editor, formatting actions, query history, execution,
errors, and results. Execution belongs to the injected data source; the UI owns
only draft and presentation state.

`QueryResultsTable` is the reusable public table for typed query columns, rows,
sorting, and pagination.

```tsx
<script lang="ts">
  import { QueryResultsTable } from "@beancount-js/ui";
</script>

<QueryResultsTable {columns} {rows} pagination={page} />
```

The stories cover populated results, empty and error states, formatting,
history, search controls, keyboard execution, table padding, and compact layout.
