# Public component reference

The following components are exported from `@beancount-js/ui`. Prefer
`BeancountApplication` for the complete routed experience; use the smaller
exports when a host intentionally owns shell or route composition.

## Application composition

| Component              | Purpose                                        | Catalog documentation                                  |
| ---------------------- | ---------------------------------------------- | ------------------------------------------------------ |
| `BeancountApplication` | Complete controller-backed application         | [Application](?path=/docs/beancount-application--docs) |
| `BeancountAppShell`    | Beancount composition of the Design Core shell | [Shell](?path=/docs/beancount-shell--docs)             |
